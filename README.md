# RAG Pipeline

A learning project implementing Retrieval-Augmented Generation (RAG) over a small
corpus of company Wikipedia articles (Google, Microsoft, Nvidia, SpaceX, Tesla).

It covers the full RAG lifecycle: **ingestion** (load → chunk → embed → store),
**retrieval** (semantic search over a vector DB), and **generation** (answering
questions with an LLM grounded in retrieved context), including a
**history-aware** conversational variant.

## Architecture

| File | Role |
|------|------|
| `ingestion_pipeline.py` | Loads `.txt` docs, splits into chunks, embeds them, and persists a ChromaDB vector store to `db/chroma_db`. |
| `retrieval_pipeline.py` | Loads the vector store and exposes `retrieve(query, k=5)`. Run directly to inspect retrieved chunks. |
| `answer_generation.py` | Single-shot RAG: retrieve relevant chunks → ask the LLM to answer using only those chunks. |
| `history_aware_generation.py` | Conversational RAG: rewrites follow-up questions into standalone queries using chat history, then retrieves and answers. |

### Stack

- **Embeddings:** `BAAI/bge-base-en-v1.5` — a local HuggingFace model (768-dim).
  Runs on your machine, no API key, no quota, and documents never leave the machine.
- **Vector store:** ChromaDB (cosine similarity).
- **LLM:** Claude (`claude-sonnet-4-6`) via an Anthropic-compatible endpoint.
- **Framework:** LangChain.

## Setup

1. **Create and activate a virtual environment**

   ```bash
   python -m venv venv
   # Windows (PowerShell):
   venv\Scripts\Activate.ps1
   # macOS/Linux:
   source venv/bin/activate
   ```

2. **Install dependencies**

   ```bash
   pip install langchain langchain-community langchain-chroma langchain-huggingface \
               langchain-anthropic langchain-text-splitters sentence-transformers \
               python-dotenv
   ```

3. **Configure environment variables**

   Copy `.env.example` to `.env` and fill in your values:

   ```bash
   cp .env.example .env
   ```

   ```
   ANTHROPIC_BASE_URL=https://your-anthropic-compatible-endpoint/
   ANTHROPIC_AUTH_TOKEN=your-token
   ```

   > **Note:** `.env` is gitignored — never commit your tokens.

## Usage

Run the steps in order. **Ingestion must run first** to build the vector store.

```bash
# 1. Build the vector store (downloads the embedding model on first run)
python ingestion_pipeline.py

# 2. (optional) Inspect what retrieval returns for a query
python retrieval_pipeline.py

# 3. Ask a single question
python answer_generation.py

# 4. Or start an interactive, history-aware chat
python history_aware_generation.py
```

The conversational mode supports follow-up questions that refer back to earlier
turns, e.g.:

```
Who founded SpaceX?
What year did he start it?
Which island does it use for launches in the Pacific?
```

## Notes

- The `db/` directory (the vector store) is gitignored and regenerated by
  `ingestion_pipeline.py`.
- If you change the embedding model, delete `db/chroma_db` and re-run ingestion —
  vectors from different models have different dimensions and aren't compatible.
- On Windows, the scripts set UTF-8 output and read files as `utf-8-sig` to handle
  encoding/BOM issues.
